# TRABALHO ALAN FILIPE RONCOLATO SITE

## Sobre o projeto

Este projeto é o desafio 02 da disciplina de Design e Desenvolvimento Frontend. A proposta era montar um card de resumo do pedido parecido com o exemplo passado pelo professor, usando HTML e CSS.

## A página

O card mostra a imagem de uma pessoa ouvindo música, o plano anual e o preço da assinatura. As imagens são as mesmas do desafio, e a fonte usada é a Red Hat Display. O CSS cuida das cores, dos espaçamentos e do alinhamento com Flexbox. Também tem ajustes para telas menores e mudança de cor nos botões quando o mouse passa por cima.

## Os botões

Os botões são apenas visuais, então não fazem pagamento, cancelamento ou troca de plano. Não foi usado JavaScript.

## Como abrir

Para abrir, basta baixar a pasta e abrir o sample.html no navegador. O style.css e as pastas images e fonts precisam ficar junto do arquivo HTML. Não precisa instalar nada, e a página também abre sem internet.
